# Retailing Gating Artifacts

This directory is reserved for generated Gating consumer artifacts only.

Allowed contents include reports, evidence, cache data, checksums, and other generated verification output.

Normative policy, executable rules, profiles, schemas, and the Gating CLI belong to the installed `gating/gate` package and canonical Symfony/application configuration surfaces.

Do not copy the Gating engine or policy tree into this directory.

See Canon052 in Canonization for the authoritative consumer integration contract.
